URLL(ユーアールエルエル)は、⌥+G のようなショートカットキー一発で、 よく見る Web ページやアプリを開ける小さなアプリです。ブックマークを探す手間を、ぜんぶキーにおまかせ。

できること

毎日の「あのページ開きたい」を、キーひとつで。

どのアプリを使っていても、登録したキーを押すだけ。メニューバーにちょこんと住んで、Dock は散らかしません。

URL ジャンプ

キーと URL を組にして登録。⌥⌘⌃ とほかのキーの組み合わせで、ブラウザでページが開きます。shortcuts:// や mailto: も OK。

アプリ起動

URL のかわりにアプリも登録できます。キーを押すと、そのアプリが起動して前に出てきます。ターミナルやメモをすぐ呼び出したいときに。

キー操作の置きかえ

あるキーを押したら、別のキーを前面のアプリへ送ります。たとえば ⌥W を押すと、タブを閉じる ⌘W に。よく使う操作は一覧から選ぶだけ。

画面のようす

忘れても大丈夫。
⌃/ で一覧が出ます。

どのアプリの上でも、画面のまん中に「キー → 開く先」の一覧がふわっと出ます。行をクリックしてもそのまま開けます。もう一度 ⌃/ か Esc で閉じます。

※ 一覧の画面は説明用のイメージです。実際の画面写真はこれから差しかえます。

使い方

はじめかたは 3 ステップ。

  1. 1

    アプリを入れる

    ダウンロードした DMG ファイルを開いて、URLL を「アプリケーション」フォルダへドラッグします。

  2. 2

    はじめて開く

    URLL は Apple の公証を受けたアプリです。アプリケーションフォルダの URLL をダブルクリックすれば開きます。くわしい手順は下にあります。

  3. 3

    キーを登録

    設定画面が自動で出ます。名前と URL を入れて、キーのボタンを押してから登録したいキーを押せば完了。

「キー操作」を使うときだけ、システム設定 → プライバシーとセキュリティ → アクセシビリティ で URLL をオンにします。URL やアプリを開くだけなら、この許可はいりません。

はじめて開くときの手順（くわしく）

URLL は Apple の公証（ノータリゼーション）を受けたアプリです。次の順に進めてください。

  1. DMG ファイルをダウンロードして開き、URLL を「アプリケーション」フォルダへドラッグします。
  2. URLL をダブルクリックして開きます。「インターネットからダウンロードされたアプリです」と聞かれたら「開く」を押します。
  3. URLL が起動して、メニューバーにアイコンが出ます。
  4. キー操作を使うときは、設定画面の「キー操作」タブで「許可する…」を押し、アクセシビリティで URLL をオンにします。
